# Mapa para agentes

Para quem vai mexer numa feature: procure a linha dela antes de abrir o código
(`rg -n "termo" docs/agents/mapa.md`). Cada linha diz onde moram o núcleo, o
artefato gerado, o aplicador, o IPC e os testes. Vem do `AGENTS.md`, onde ficava
inteiro (#43); mude a linha daqui quando um arquivo mudar de papel.

## Mapa para agentes (onde cada coisa mora)

Para não se perder entre as camadas — a regra do repo: **invariante de domínio
mora no núcleo Bend (com leis+provas); a interface e o aplicador ficam em JS com
teste; o IPC liga ao main; os testes cobrem os dois lados.** Muitas linhas abaixo
ainda mostram núcleos de interface de antes do [ADR 0001](../adr/0001-bend-so-para-invariantes.md):
eles saem do Bend quando um ticket já precisar mexer neles.
