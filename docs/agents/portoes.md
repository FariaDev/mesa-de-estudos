# Portões e rodada local

Detalhe dos portões de verificação. Vem do `AGENTS.md`, onde ficava inteiro
(#43); o `AGENTS.md` guarda só os comandos.

- Portão do núcleo: `npm run verify:bend` (em `desk/`) exige a toolchain pinada e roda build + provas. Antes do bend, `core/unsafe-scan.mjs` recusa `@unsafe`, def estrangeira (`def nome?(`) e import por string em `core/**/*.bend`: o bend 2.0.27 aceitava prova falsa por um `@unsafe` importado (#47). O 2.0.37 fixado na #49 recusa sozinho; a varredura fica como segunda camada, que não depende da toolchain. O `Nat` entra e sai dos artefatos como `number` (#49): converta pela casca `desk/src/bend-nat.mjs` (`toNat`, `wholeNat`, `roundNat`), e `tests/bend-nat.test.mjs` reprova `BigInt(` e literal `0n` fora dela. O hook `.githooks/pre-push` o roda antes de todo push; `git push --no-verify` é a saída de emergência.
- Rodada local: `npm test` usa cache do portão por conteúdo (`core/**`, artefatos gerados, verificadores de paridade com os hosts que eles importam, e `package.json`; `MESA_GATE_CACHE=0 npm test` força) e `npm run hunts` roda os `tests/hunt-*.mjs` em paralelo (2 por vez) e `npm run ui` faz o mesmo com os testes de janela (3 por vez) (`*-ui.mjs`, `*-ipc-smoke.mjs`, `ui-smoke`; `npm run ui -- composer,calc` filtra por nome (vários, separados por vírgula), `--jobs N` e `--verbose` valem nos dois). O corredor comum é `tests/run-suite.mjs`: arquivo que sai com 77 e `PULADO: motivo` na primeira linha aparece como pulado no resumo — pular nunca reprova a rodada, mas nunca some calado. Quem cria runtime ou capturas (`newRuntime`, `screenshotDirectory`) as apaga ao sair com 0; na falha ficam para investigação, e `MESA_KEEP_RUNTIME=1` as mantém também no sucesso. As capturas de tela dos testes de janela são material de revisão visual, não asserção: só saem com `MESA_REVIEW_SHOTS=1` (pasta `docs/reviews/<data>/`) ou `MESA_REVIEW_SHOTS=<pasta>`. O hook de push continua sem cache.
- Teste de janela mede e redimensiona a janela da página (`resizeWindow`/`pageWindow` de `tests/helpers.mjs`), nunca `BrowserWindow.getAllWindows()[0]`: as prévias abrem janelas escondidas que podem vir antes (`tests/test-harness.test.mjs` reprova o uso). Nenhum Electron de teste sobra: `testEnv` instala a guarda de `tests/proc-tree.mjs` (SIGKILL na árvore na saída e em SIGTERM/SIGINT/SIGHUP), `closeApp` fecha com prazo, o corredor manda SIGTERM no estouro e SIGKILL 5 s depois e mata o que o teste deixou vivo, e o `npm test` roda com `--test-timeout=180000 --test-force-exit`.
- Janela de teste: um por vez por máquina. Duas sessões que abrem Electron ao mesmo tempo disputam CPU e GPU, e o teste que passa sozinho estoura prazo e vira "intermitente". Antes de rodar `npm run ui` ou `npm run hunts`, confira que nenhuma outra sessão (ou worktree) está com a rodada aberta; sobrando um Electron de teste, registre de onde ele veio em vez de só matá-lo.
- Rodada por área, rodada cheia no fim (#48): durante o trabalho rode só a suíte da área que você mexeu com o filtro abaixo (os mesmos nomes valem em `npm run ui` e `npm run hunts`); a rodada cheia (`npm run ui` e `npm run hunts`, sem filtro) fica para o fim, antes de dar por pronto.

  | Área | Filtro |
  |---|---|
  | PDF e leitor | `npm run ui -- pdf,reader` e `npm run hunts -- pdf` |
  | Chat principal, turnos e fila | `npm run ui -- chat,composer,send,tutor,timeline,model-indicator,settled,prompt-capture` e `npm run hunts -- chat,queue,timeline,chaos` |
  | Chat lateral | `npm run ui -- sidechat` |
  | Atividades | `npm run ui -- activity,mesa-interactive,bundle` e `npm run hunts -- activity` |
  | Calculadora | `npm run ui -- calc` e `npm run hunts -- calc` |
  | Estudo livre e materiais | `npm run ui -- free-study,material` |
  | Configurações, tema e ajuda | `npm run ui -- settings,accent,color-roles,about,guide` |
  | Conferir | `npm run ui -- conferir` |
  | Revisão, caderno e estatísticas | `npm run ui -- review,study-,improvements,dialog-standard` e `npm run hunts -- review,study` |
  | Layout, janela e primeira execução | `npm run ui -- layout,responsive,splitter,topbar,first-run,qol,ui-smoke` e `npm run hunts -- shell,nav` |

- Esperas nos testes de janela (#48): o teste espera um estado, não um tempo. `tests/waits.mjs` tem `pollUntil` (lê até uma regra aprovar, com erro que diz o valor visto), `layoutStable` (o retângulo parou), `nextFrames` e `pdfRenderIdle` (o leitor parou de pintar). `waitForTimeout`/`sleep` só ficam onde o tempo é o que se testa (debounce, timeout, "nada acontece em N ms", janela de medição de batimento), com o comentário `espera fixa: <motivo>` na linha ou na de cima; `tests/ui-waits.test.mjs` conta as que não têm e reprova acima do teto, que só pode cair.
- Medir antes de mexer (#48): o corredor grava uma linha por arquivo em `desk/.runtime/suite-tempos.jsonl` e o custo de abrir a janela em `launch-tempos.jsonl` (fora do git). `node tests/suite-tempos.mjs [--suite hunts|janelas]` lista o total por rodada e os arquivos mais lentos; o resumo do corredor já mostra os 10 mais lentos da rodada.
- Rodada longa de Electron vai em segundo plano (#48): uma ferramenta que mata o comando por prazo em primeiro plano deixa Electron órfão. Se sobrar um, registre de onde veio antes de matá-lo.
- Opt-in, fora do `npm test` (cada um abre o Pi real ou o SDK instalado): `node tests/native-rpc.mjs` (conversa temporária com Pi/provedor reais; usa o `rpc.cjs`, o `pi.cjs` e o perfil fixado da Mesa), `node tests/native-mcp.mjs` (SDK do Pi com servidor MCP local, sem modelo) e `node tests/native-{tutor-pdf,activity-tool,tool-parity}.mjs`. Desde a #50 eles só exercitam a Mesa (antes `native-rpc` e `native-mcp` também apontavam para `chat/`).
- Claude Code nos testes de janela (#51): o `testEnv` aponta `LEARNING_DESK_CLAUDE_HOME` para um Claude de guarda (`--version` = 0.0.0, fora da faixa) no lugar do `~/.local/bin/claude` real, que dentro da faixa passaria do `--version` ao `auth status`. A Mesa ainda acha um launcher (o boot liga com o SDK sintético), e qualquer detecção o recusa antes do login. Teste que quer a própria casa passa `LEARNING_DESK_CLAUDE_HOME: ''` junto com `HOME`.
- App empacotado (#51, só macOS): `npm run test:packaged` monta o `Mesa de Estudos.app` numa pasta temporária com a rotina do `install-app` (`installBundle` em `desk/bundle-runtime.cjs`; sem assinatura, sem atalho em `~/Applications`, sem tocar no app do repositório) e sobe pelo executável do bundle com um Claude Code falso em `~/.local/bin` de uma casa temporária: dentro da faixa conecta, mais nova que a testada conecta com aviso, série nova recusa com a frase. Opt-in, fora do `npm run ui`.
- `npm run doctor` (`desk/scripts/doctor.mjs`) confere Pi, políticas, fontes das matérias e escrita. Desde a #50 ele não checa mais o bilhete Conversa → Mesa nem a pasta `handoff/` do runtime.
