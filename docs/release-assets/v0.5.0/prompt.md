## Prompt de geração

Use case: ads-marketing.
Create ONE finished premium product-release overview image, a beautiful Apple keynote-style bento feature board, for the Portuguese desktop studying app Mesa de Estudos version 0.5.0. The user will send this image to a friend. New original raster image, landscape 3:2, very high resolution, crisp, readable Portuguese text.

VISUAL IDENTITY: faithfully evoke Mesa's actual UI: near-white #fcfcfc canvas, white surfaces, soft neutral gray hairline borders, dark charcoal typography, restrained saturated purple #6020df accents, pale lavender selection pills. System sans-serif similar to SF Pro / Segoe UI. Mesa app icon is a simple purple rounded square containing a bold white uppercase M. No Apple logo or device hardware. No garish gradients, no glossy glass, no generic AI robots. Generous spacing, perfectly aligned elegant rounded rectangular cards of different sizes, subtle shadows, beautifully disciplined keynote design. This is a designed promotional feature board, NOT a screenshot or website. No tiny unreadable mock UI. Feature titles must be large and impeccably spelled. Distinct simple illustrations, purple UI fragments and icons should tell the story in each card.

LAYOUT: title strip at top with the Mesa M icon and large exact title "Mesa de Estudos 0.5.0" and subtitle "Tudo novo para o seu estudo."
Below that, a compact balanced bento mosaic with all the cards listed here. Give the PDF and Livre cards the largest visual emphasis, chat lateral another wide tile, and the rest clear smaller cards. Include every feature once. Minimize small prose; use exactly the short titles and subtitles below. It must feel premium and uncluttered, with strong hierarchy. No redundant large central logo wasting the feature space.

## Ajuste final

Preservar composição, textos, paleta e demais cartões. No cartão Configurações completas, usar três opções: Rascunho .xopp, Encerrar por hoje, Dois leitores. No cartão Interface mais confortável, usar Montar PDF como título do diálogo e Salvar PDF no botão. Não sugerir salvamento automático, confirmação ao fechar o aplicativo ou leitor externo.
